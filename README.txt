FINAL GITHUB WEBSITE PACKAGE

1. Download and unzip this ZIP file.
2. Open the unzipped folder.
3. Upload index.html, styles.css, script.js and the complete assets folder to your new GitHub repository.
4. Do not upload the ZIP itself.
5. Commit the files.
6. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.

IMPORTANT:
The new Sarah files and website preview are included.
The other eleven animal pictures temporarily load from your older website, so do not delete the old repository yet.
